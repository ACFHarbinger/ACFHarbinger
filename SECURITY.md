| Version | Supported          |

| `main`  | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a security vulnerability within this repository or associated automation scripts:

1. **Do NOT disclose publicly**: Please avoid opening public issues for security vulnerabilities.
2. **Email Disclosure**: Send a detailed vulnerability report privately to [afonso.fernandes100@gmail.com](mailto:afonso.fernandes100@gmail.com).
3. **Include Details**:
   - Description of the issue and potential impact
   - Steps or proof-of-concept to reproduce
   - Any suggested mitigations or fixes

You will receive an acknowledgment within 48 hours, followed by updates as the issue is resolved.
