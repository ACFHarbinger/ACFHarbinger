### 🌟 Open Source & Submodule Integrations

This profile is assembled from two vendored submodules plus a scheduled GitHub Actions pipeline:

| Submodule | Role |
| :--- | :--- |
| 📦 [`submodules/metrics`](https://github.com/ACFHarbinger/metrics) | Infocards, isometric calendar, languages, activity, and achievements — rendered into `profile/*.svg` twice a day |
| 🎨 [`submodules/markdown-badges`](https://github.com/ACFHarbinger/markdown-badges) | Curated Shields.io / Simple Icons badge catalog used throughout this README |

Refresh is automatic (`00:00` and `12:00` UTC, plus manual `workflow_dispatch`). A personal access token in `METRICS_TOKEN` (or `PAT_TOKEN` / `GH_PAT`) is recommended so GraphQL plugins stay within rate limits; `GITHUB_TOKEN` is the fallback.
