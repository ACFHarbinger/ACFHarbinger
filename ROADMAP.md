## 🎯 Active & Upcoming Milestones

### 1. 🔬 Deep Reinforcement Learning & Operations Research (OR)

- [x] **Benchmark Frameworks**: Establish evaluation pipelines for classical vs. learning-based combinatorial optimization benchmarks (TSP, VRP, Knapsack, Scheduling).
- [ ] **Neural Combinatorial Optimization**: Design hybrid solvers coupling Graph Neural Networks (GNNs) and Pointer Networks with local search heuristics (LKH, 2-Opt).
- [ ] **Multi-Agent Decision Systems**: Explore cooperative multi-agent RL (MARL) for complex resource allocation and logistics scenarios.
- [ ] **Publication & Open Benchmarking**: Publish research findings, reproducible baselines, and open-source datasets for the scientific community.

### 2. 🎮 Game Development & Pixel Art

- [x] **Foundational Pixel Art Pipeline**: Establish visual art pipelines, palette management, and animation sprite sheets using Aseprite.
- [ ] **2D Roguelike / Optimization Sandbox**: Develop a custom indie game prototype integrating optimization mechanics with responsive real-time gameplay.
- [ ] **Procedural Level Generation**: Implement graph-based dungeon and world generation algorithms with constraint satisfaction (WFC / Wave Function Collapse).
- [ ] **Shader & Visual Polish**: Craft custom GLSL shaders for dynamic lighting, water reflections, and retro CRT styling.

### 3. 🌐 Web, Mobile & Developer Tooling

- [x] **Automated Profile Telemetry**: Continuous dynamic generation of GitHub statistics, language analytics, and SVG telemetry badges.
- [ ] **Interactive Research Portfolio**: Upgrade GitHub Pages showcase with interactive visualization widgets for RL trajectories and OR algorithms.
- [ ] **CLI Productivity Utilities**: Open-source lightweight CLI tools in Rust and Python for automated research workflow and metric logging.
- [ ] **Cross-Platform Mobile Tools**: Build lightweight companion utilities using Kotlin / Android and modern cross-platform toolchains.
