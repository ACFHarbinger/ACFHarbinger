## [2.1.0] - 2026-08-20

### Added
- Dynamic rank calculation algorithm based on official GitHub Readme Stats logarithmic and exponential distribution metrics.
- Custom SVG generation script (`generate_stats.py`) with support for automated language statistics and custom Tokyo Night / Cyberpunk themes.
- Submodule architecture for badge assets and metrics automation plugins.

### Changed
- Refactored banner header to dynamic transparent SVG typography.
- Enhanced profile layout with dedicated sections for Research Focus, Tech Stack, Live Telemetry, and Featured Projects.

## [2.0.0] - 2026-08-15

- GitHub Actions daily cron workflow for automated statistics refresh.
- Custom SVG cards for language usage distribution and overall GitHub statistics.
- Interactive social links for Email, LinkedIn, X, ORCID, and GitHub Pages.
